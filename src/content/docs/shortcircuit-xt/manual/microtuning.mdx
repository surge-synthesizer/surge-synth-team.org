Tuning is a single setting for the whole instance. Open the tuning menu from the **Tune** button in
the header, or from **Tuning** in the main menu.

## Tuning modes

- **Use MTS-ESP**: follows an MTS-ESP master. On by default. Below it the menu shows **MTS-ESP
  source found** or **No MTS-ESP source**. With no master connected, Shortcircuit XT plays in
  12-TET.
- **MTS-ESP Updates** sets how MTS-ESP retunes, and is greyed out while MTS-ESP is off:
  - **Continuous**: retunes notes while they sound. The default.
  - **Note-On Only**: fixes each note's pitch when it starts.
- **Without MTS-ESP** lists the tunings that do not use it. Choosing one turns MTS-ESP off, and
  **Use MTS-ESP** turns it back on with the update rate it had.
  - **Twelve-Tone Equal Temperament**
  - **SCL/KBM Scale**: uses a Scala scale and keyboard mapping. Available once a scale is loaded.

## Skipping tuning for a part

**Skip Tuning for Part** lists the 16 parts. A ticked part ignores MTS-ESP and SCL/KBM and plays in
12-TET. The setting is saved with the part.

## Scala files

The **SCL/KBM** submenu offers **Load SCL...**, **Load KBM...**, **Edit SCL/KBM...** and **Reset
to No SCL/KBM**.

Loading a file applies it and switches to SCL/KBM mode. A KBM loaded without an SCL maps a 12-TET
scale. If a file fails to parse, the current tuning is kept.

**Edit SCL/KBM...**, or Alt/Opt+T, opens a text editor with **SCL** and **KBM** tabs. **Load...**
fills the text box and **Apply** retunes the instrument.

The loaded scale is saved with your DAW session, not in multi files.

## Tuning and zones

Shortcircuit XT retunes the incoming note first, then uses the nearest 12-TET key to that tuned
pitch to choose zones. Each sample then plays from its root key at the tuned pitch.

Keyswitches and other trigger conditions use the untuned MIDI key.

Part, group and zone tuning offsets are in 12-TET semitones.
