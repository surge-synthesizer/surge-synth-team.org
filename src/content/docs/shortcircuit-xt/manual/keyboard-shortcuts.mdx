Shortcircuit XT ships with a set of shortcuts, and you can change any of them.

## The shortcut editor

Open it with **Keyboard Shortcuts...** in the main menu under the Shortcircuit logo, or with
Alt/Opt+B.

Actions are listed under **General**, **Screens** and **Selection and Clipboard**. Each row is
one action, with a switch on the left, its key, a **Learn** button and a **Reset** button.

- **Learn** takes the next key you press. Escape stops learning and keeps the old key.
- The switch turns an action off without losing its key.
- **Reset** returns one action to its default, **Reset All** returns every action.
- **OK** applies and saves; **Cancel** leaves everything as it was.

If the key you press already belongs to another action, the editor says so and waits for you to
try another.

Your changes are saved in `ShortcircuitXTKeyboardMappings.xml`, in your user folder beside the
`Patches` and `Themes` folders. Only the actions you changed are written, so defaults which
change in a later release still reach you.

## How a key finds its target

Some actions are global: undo, switching screens, opening a screen. The rest act on whichever
panel has the keyboard focus, so **Copy** copies a zone in the zone list and a group in the
group list.

Clicking a row in the zone, group or browser list gives the keys to that list. Clicking a part
card, a processor, a modulation row or the variant tabs gives the clipboard keys to that.

Text fields, and controls like knobs, take the keys first while they are focused.

## The defaults

Cmd is the Mac key; Ctrl is Windows and Linux. Opt is the Mac key; Alt is Windows and Linux.

### Anywhere

| Action | Key |
| --- | --- |
| Undo | Cmd/Ctrl+Z |
| Redo | Cmd+Shift+Z on Mac, Ctrl+Y elsewhere |
| Keyboard Shortcuts | Alt/Opt+B |
| Tuning Editor | Alt/Opt+T |
| Show Log, About Shortcircuit XT | unassigned |
| Edit Zones, Groups, Parts | Cmd/Ctrl+1, 2, 3 |
| Mixer Screen, Play Screen | Cmd/Ctrl+4, 5 |
| Swap Group and Zone Editing | Alt/Opt+G |

### Selection and clipboard

| Action | Key |
| --- | --- |
| Select All | Cmd/Ctrl+A |
| Select Previous, Select Next | Up, Down |
| Open or Load | Return |
| Collapse, Expand | Left, Right |
| Rename | Cmd/Ctrl+R |
| Copy, Cut, Paste, Duplicate | Cmd/Ctrl+C, X, V, D |
| Delete | Backspace on Mac, Delete elsewhere |

Where each one acts:

- **Zone list**: selects, renames, copies, cuts, pastes, duplicates and deletes zones. Up and
  Down step from the lead zone through the rows you can see, so zones inside a folded group are
  skipped. Left and Right fold and unfold the lead zone's group. Paste lands after the lead zone,
  or at the end of the lead group.
- **Group list**: the same, on groups. Paste lands after the lead group. Deleting several groups
  is a single undo step.
- **Mapping pane**: select all, copy, cut, paste, duplicate and delete, on zones. In group
  editing only copy and paste act, unless **Allow Zone Edits in Group Mode** is on.
- **Part card**: copy and paste the whole part.
- **Variant tabs**: copy, cut and paste the shown variant. Paste puts the copy after the shown
  variant.
- **Processor**: copy, cut and paste the processor. Cut sets the slot to none.
- **Modulation row**: copy, cut and paste the row holding the focused control. Cut clears the
  row.
- **[Browser](/shortcircuit-xt/manual/ui-browser/)**: Up and Down move through the list. Right
  enters a folder or opens an instrument file such as an SF2; Left closes it or goes up a folder.
  Return does what a double-click does.

Rename acts on the lead zone or group. Copy, Cut, Duplicate and Delete act on everything
selected, and Cut is a single undo step.

While renaming a zone or group, **Tab** keeps the name and moves the rename to the next row, and
**Shift+Tab** to the previous one.

In the browser, typing a name jumps to the first entry starting with it. Letters typed within a
second build up the name; typing the same letter again moves to the next match.

## Keys you cannot change

- **Escape** closes a dialog and cancels a type-in; **Return** confirms.
- **Tab** and **Shift+Tab** move the keyboard focus.
- On a focused knob or switch: **Up** and **Down** change the value, **Shift** for a finer step
  and Cmd/Ctrl for a coarser one, **Home** and **End** for the extremes, **Delete** to return to
  the default, **Shift+Return** to type a value, and **Shift+F10** or the Menu key for the
  right-click menu.
- Text fields keep their own editing and selection keys.
