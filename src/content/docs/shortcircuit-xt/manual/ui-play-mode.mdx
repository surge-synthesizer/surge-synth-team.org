The **PLAY** screen is for playing a finished multi. Open it with **PLAY** in the header, or
Cmd/Ctrl+5.

It lists every active part. Each row has the part card, with the same controls as in the edit
screen, and the part's 16 macros. The browser is on the right.

The **Play Screen** menu chooses:

- **Expanded Display**: each part shows a description and two rows of eight macros.
- **Compressed Display**: each part shows one row of macros, switched between **1-8** and
  **9-16**.

Macro names are edited on the edit screen, not here.
