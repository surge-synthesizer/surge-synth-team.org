Download a build from the [product page](/shortcircuit-xt/) and run the installer.

Shortcircuit XT is an instrument. It has no audio inputs, one note input, and 21 stereo outputs:
**Main Out** and **Out 1** to **Out 20**.

## Windows

The installer offers the CLAP and VST3 formats and the standalone application. A ZIP of the
same files is also available.

## macOS

The installer offers the CLAP, VST3 and AU (v2) formats and the standalone application.

macOS 10.15 or later is required.

## Linux

The CLAP and VST3 formats and the standalone application are provided in a ZIP file.

## Building from source

Steps for building Shortcircuit XT yourself are in the README of the
[GitHub repository](https://github.com/surge-synthesizer/shortcircuit-xt).

## Your user folder

Shortcircuit XT keeps your files in `Documents/Surge Synth Team/Shortcircuit XT`, creating it on
first run. It holds these folders:

- `Patches`, with user templates in `Patches/Templates`
- `Themes`
- `Modulator Presets`
- `FX Presets`

To run portably, put a folder called `ShortcircuitXTUserData` next to the plugin, and Shortcircuit
XT will use that instead.

### On Linux

Linux has no fixed Documents folder, so Shortcircuit XT follows the XDG user directories. Your
documents folder is the one `XDG_DOCUMENTS_DIR` names in `~/.config/user-dirs.dirs` (or in
`$XDG_CONFIG_HOME/user-dirs.dirs` if you set that), or `~/Documents` if it isn't set.

- With a documents folder, your files go in `Surge Synth Team/Shortcircuit XT` inside it.
- If you have switched your documents folder off, which xdg-user-dirs records by setting
  `XDG_DOCUMENTS_DIR` to your home folder, and there is no `~/Documents`, they go in
  `~/.Surge Synth Team/Shortcircuit XT`.
- A folder that already exists is used before a new one is made. That includes a
  `Shortcircuit XT` folder directly in your documents folder, which is where earlier versions put it.

To keep the files somewhere else, point `XDG_DOCUMENTS_DIR` there, or use a portable
`ShortcircuitXTUserData` folder.
