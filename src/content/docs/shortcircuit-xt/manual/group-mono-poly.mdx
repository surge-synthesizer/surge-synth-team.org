Play mode is set per group, in the **GROUP SETTINGS** card of the **GROUPS** sidebar tab.

- **Poly**: every note plays its own voices.
- **Mono**: one note at a time. A new note stops the old voice and starts a new one, restarting
  the sample and envelopes.
- **Legato**: one note at a time. A new note played while the old one is held changes the pitch
  without restarting the sample or envelopes.

Because play mode belongs to the group, two mono groups in one part each play their own note.

## Note priority

In Mono and Legato, **Note Priority** chooses which held note sounds: **Latest**, **Highest** or
**Lowest**. When a note is released, the group returns to the next held note by the same rule.

## Glide

Glide is available in Mono and Legato. Its mode button chooses between:

- **TIME**: every glide takes the set time.
- **RATE**: the set time is for an octave, so wider intervals take longer.

A glide time of zero turns glide off.
